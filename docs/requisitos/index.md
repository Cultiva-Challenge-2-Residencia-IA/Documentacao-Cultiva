# Requisitos

Os requisitos transformam as premissas, personas e riscos em itens que a equipe consegue desenvolver e testar.

!!! info "Versão vigente"
    A documentação segue a versão **refatorada** dos requisitos (numeração `RF-A` e `RF-IA`), a mesma usada no documento principal. Falta confirmar com a equipe que ela substitui a lista original.

## Como ler

- **RF-A:** requisitos funcionais de software convencional.
- **RF-IA:** requisitos funcionais aplicados à IA.
- **RNF:** requisitos não funcionais, sempre com métrica.
- **RF-B:** itens de backlog, fora do escopo atual.
- **Prioridade:** Essencial (MVP), Importante, Desejável.
- Valores marcados **(proposta)** ainda precisam ser calibrados.
